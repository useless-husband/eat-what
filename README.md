# 🍜 今天吃什麼？

選擇困難救星。一個純前端的美食轉盤，按下「轉！」就幫你決定今天吃什麼。

## 功能

- 🎡 轉盤動畫，隨機選出一個選項
- ✏️ 自訂選項：可新增、刪除，最多 16 個
- 💾 自動記住你的清單（存在瀏覽器 localStorage）
- 📱 手機、電腦都能用，不需要安裝任何東西

## 使用方式

直接開啟 `index.html` 就能用，或到線上版本：

👉 https://useless-husband.github.io/eat-what/

## 技術

純 HTML + CSS + JavaScript（Canvas 畫轉盤），沒有任何相依套件。
